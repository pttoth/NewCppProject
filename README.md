# pttoth's new cpp project template

Template new project containing:
- instant support for my multiplatform needs
- decent project directory structure
- maintenance helper scripts
- cmake setup tuned to above needs

# How to use

## Generate project
Use 'script/generate_project.sh'.

## Build project for specific platform

### supported platforms
- debian_amd64
- debian_arm64 (experimental: not yet implemented)
- win64 (not yet implemented)

Use the 'script/build_\<platform\>' scripts.
